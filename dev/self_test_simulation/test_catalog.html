7. Roadmap (S5 expanded) and gates

S2 (6-sec staggering + largest remainder) → S0c (terminal waiting fix) → S3 → S4 (ServiceDiscretizer) → S5a (CA/CD→TT) → S5b (agent TA/TD→TT; dual-path gate ≤ 1 interval) → S5c (TT→v̄) → S5d (SQM t_F/t_Q + x_f(t) reconstruction; ST04a full) → S6 tandem → L0/L1 replay → F05 spillback

Plus the time-contract equivalence gate once S1/S2 land: the same λ(t) as (A) period pieces and (B) one period + departure profile must give A_A(t) ≈ A_B(t) ≤ 1 veh.
